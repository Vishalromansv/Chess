# Chess Tournament Manager

A responsive, offline-first Chess Tournament Manager built for over-the-board local chess tournaments using **Python**, **Streamlit**, and **SQLite**.

## Features
- **Dynamic Player Management**: Add, search, edit, and select 2 to 16 players.
- **Automatic Grouping**: Intelligent default recommendations for player counts from 2 to 16.
- **Fixture Generation**: Automatic round-robin and group fixture scheduling with no duplicate pairings or self-matches.
- **Dual-Touch Chess Clock**: Split-screen touch chess clock with customizable time controls, increments, pause/resume, and audio-visual low-time warnings.
- **Offline & Local Wi-Fi Ready**: Fully functional without internet connection. Runs locally and supports mobile device connection over the same local network.
